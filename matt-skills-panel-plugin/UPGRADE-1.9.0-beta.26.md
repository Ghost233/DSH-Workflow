# Matt 1.9.0-beta.26 升级记录

从 `584127b1152ffdf04eeb2363b0a03d7cbdaa1bd2`（beta.18）升级到 `b79bbc4c37eac8f83107bf5321e9cd421b400d2d`（beta.26）。目标来自 npm 正式发布元数据的 `gitHead`，并已核对该官方提交的开发清单和发布清单均为 `1.9.0-beta.26`。GitHub Releases 列表尚未列出这次发布，未用未发布主线代替。

## 合并范围

三方提案涉及 145 个路径：123 个自动合并、13 个新增、6 处冲突和 3 个删除项。自动合并与新增项均纳入双轴审查。删除的旧日志实现逐字等于原基准，生产引用已改为日志包和派生产物。

保留项目的 macOS/POSIX 路径规则、仓库账号环境与 BASH_ENV 注入、外置中文技能、自更新停用，以及构建不写用户 profile 的边界。生成的更新器代码继续使用已经固定的 0.18.39 与本地命名空间。

新版技能详情的文件预览通过 DSH 当前工作区的技能注册表读取。正文和预览使用同一份文件名单；同一技能中的重名文件按目录顺序确定读取结果，不产生无法完成的选择循环。`SKILL.md` 预览继续保留同目录中文译文。引用只接受文件名，不接受路径；符号链接不进入扫描名单。

工具注册保留插件卸载时取消等待及阻止晚到注册的逻辑，同时采用新版存活租约。等待定时器不持有进程，实际注册任务持有租约并在完成后释放。

技能详情在发出请求时固定工作区缓存键。同一面板切换目录后清空旧详情栈，旧目录的晚到回包不写入新目录缓存，也不阻挡新目录打开同名技能。
