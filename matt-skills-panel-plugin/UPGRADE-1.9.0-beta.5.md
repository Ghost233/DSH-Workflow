# Matt 面板 1.9.0-beta.5 升级记录

## 来源与范围

本次派生版为 `1.9.0-beta.5.workflow.1`，随 Ghost DSH Station 0.3.9 发布。用户明确选择纳入上游测试版，现有应用和服务保持原状。

上游来源为 npm `dsh-mattpocock-skills-deck@1.9.0-beta.5`，对应提交 `ea0dc0736bbfe9fea0fbe4753a524ab4fc007493`。三方比较基准为 `1428661e2cbdd543c37bc56b6182a1b7732fe11e`，本地一侧为主仓库提交 `dc6c324c1c9187bc0ffd6a73d7bbd91fe2cdacaf` 中的派生目录。

提案涉及 842 个路径，其中 411 个新增、398 个删除、26 个自动合并和 7 个文本冲突。上游将宿主、跟踪器和客户端迁到 TypeScript，并重组 `deck`、`tracker` 和共享计算核目录。旧 JavaScript 路径的删除按新源码位置处理，生成物由构建重写。

| 独立中文技能 | 保留外部提供器和工作区参数；详情缓存按工作区与技能名区分，缺文档与提供器失败分别处理。 |

| 后端选择 | 采用上游统一判定与工作区配置，保留新版本修复的调用目录检查。 |

## 构建与运行依赖

采用上游新构建管线，共享计算核从 `src/shared` 构建。增加时间参数 YAML、生成器、转译工具和类型配置，并保留 macOS ARM64 限制、许可证复制和构建不写用户 profile 的约定。

日志两端使用固定的 `dsh-log@0.3.4`。YAML 解析固定为 `yaml@2.9.1`。构建将宿主需要的代码内嵌到 `package/vendor`，生成的宿主模块使用包内相对引用。交付测试将包复制到独立临时目录，执行日志和 YAML 功能，防止本机依赖掩盖漏包。

已停用的自更新桥仍使用开发依赖 `dsh-plugin-update@0.2.0`，只生成既有桥接常量；宿主安装接口和客户端入口保持停用，不引入上游 0.18.25 的在线安装行为。

首次候选的完整 Flutter 验收有 3 项正常停止失败。隔离对照确认，卸载 Matt 后仍有工具注册重试的计时器保活。新版重试间隔由 2 秒增加到 5 秒，放大了已有的回收缺口。派生版现将等待与插件生命周期绑定，并拒绝卸载后继续探测或注册；新增回归覆盖取消、晚到结果和正常延后注册。

## 验证

发布前运行派生版构建、完整派生测试、各域类型检查及主仓库完整回归。候选 App 另核对插件本体、生产依赖、实际 Host 加载状态和界面入口。结果按实际退出码记录。

本机现有应用、插件及共享 Sentinel Core 不在本次更新范围。原有学习设计文档暂存于 Git stash，发布结束后恢复。
