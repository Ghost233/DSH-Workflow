# Matt 面板 1.9.0-beta.17 升级记录

上游基准从 `ed0ad92bd1bac8702630ab10caca76492b5134cc` 推进到正式发布标签 `v1.9.0-beta.17` 的 `9f56fcb32b53e57363ea413e28314b0c54d7eb97`。派生版本为 `1.9.0-beta.17.workflow.1`。原版子模块保持原样。

三方提案涉及 151 个路径，包含 8 处冲突。合并前核对了上游基准之后的历史和本地定制来源。上游将读取与写入迁入 Tracker 会话，修正 GraphQL 与 REST 的计账，增加写票后的增量刷新和按会话补算的权限检查。本地保留独立包标识、外置中文技能、禁用运行时自更新、账号目录注入和 macOS 路径语义。

冲突处理如下：

- 认领、发布和快照采用上游新会话实现，删除旧的重复选择及直调 gh 流程。账号环境仍由会话的默认或自定义执行器注入。
- `platformChannel` 和 `git-execution` 保留新版计账与真实点数补差，同时保留 `accountEnvFor` 和 `spawn.env`。
- 发布失败指引在上游新位置保留 macOS 安装命令。仓库名兜底只按 `/` 分隔，文件名中的反斜杠保持原义。
- 构建采用上游锁所有权守卫，同时保留项目许可证和基准记录的包内复制。技能 bootstrap 继续使用本地外置提供器版本。
- 两个上游删除的文件与本地基准逐字相同，按上游退休方案移除。

更新器依赖固定为已发布的 `dsh-plugin-update 0.18.39`，日志依赖仍为 `dsh-log 0.4.1`。新版更新器的官方派生文件带有与面板同名的 `copyText`。构建预检和回归均复现了重复声明错误。本地派生层将辅助实现放入独立作用域，仅向面板暴露原有五个取值，更新器包本体保持原样。新增回归验证剪贴板函数和五个取值均保留。

原有 macOS 测试改接新版会话入口，继续断言精确会话政策、路径大小写、反斜杠和缺少 CLI 时的安装指引。构建、类型检查、完整派生版测试和最终应用门禁按主仓发布流程执行，真实退出结果保存在 `.build/release-0.4.6/`。升级不切换现有服务，也不修改用户 profile。
