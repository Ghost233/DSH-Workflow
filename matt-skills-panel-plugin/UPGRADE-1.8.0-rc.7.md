## 本地集成差异

包名、客户端标识、工具标识保持 `dsh-workflow-matt-panel`。构建只写本派生目录，不更新用户 profile，不重启服务，也不修改上游 submodule。

上游技能详情默认查找 bundled-skills，与本项目独立中文提供器不符。派生版通过 `ctx.get('skills').get(name, { cwd })` 读取同一工作区的技能正文与来源路径；界面缓存按工作区与技能名区分。技能缺失与提供器暂不可用分别显示缺文和可重试失败。

自更新入口保持禁用，因此本次保留原有更新桥接代码与构建依赖 `dsh-plugin-update@0.2.0`。日志依赖仍为 `dsh-log@0.2.2`。这两项不随上游更新器一起升级，避免重新引入运行时自更新行为。

## GitHub 后端缺失修复

现场安装包只注册 Markdown。根因是派生目录 `.gitignore` 的 `client.js` 和 `host.js` 未限定根目录，连同后端通信源码和日志适配器一起排除。规则已改成 `/client.js` 和 `/host.js`，补入 GitHub、GitLab 的通信源码与日志适配器。新增验证从 Git 可导出的源码组成隔离目录，实际导入三个后端，避免本机忽略文件掩盖发行包缺失。

快捷选择接口现在复用正常检测中的初始化声明和用户选择优先级，跳过预检与技能查询；不再绕过标准 Matt 的 GitHub 初始化文件。安装包验收还会启动临时 Host，核对三个后端并验证 GitHub 初始化的自动选择。
