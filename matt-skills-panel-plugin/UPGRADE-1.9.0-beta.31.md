## 合并范围

初始三方提案涉及 220 个路径：179 个自动合并、27 个新增、13 个冲突和 1 个删除项。审查自动合并、新增项及冲突后，保留项目的 macOS 路径规则、独立中文技能提供器、包身份、账号环境和 BASH_ENV 注入。构建仍不写入用户 profile，npm 自更新继续停用。

新增的仓库身份补齐使用会话证据。工作区名称兜底继续只按正斜杠分段，保留目录大小写和文件名中的反斜杠。平台通道与仓库执行器采用新版步骤等待参数，同时保留 `accountEnvFor`。

删除的 `gh-queue-race.ts` 与旧基准逐字一致。新版出站准入已接管排队预算和晚到名额清理，派生版采用该删除。

时间配置生成器新增了 `scripts/lib/time-config-expr.mts` 依赖。首次构建如实记录了缺失模块错误；随后从同一官方提交原样纳入该文件，并将路径加入基准清单。

GitHub CLI 的提示采用新版诊断顺序：先区分未安装与进程 PATH 未刷新，再决定下一步。两份排查提示保持一致，并使用 macOS 启动及独立 DSH 服务的语境。GitLab 提示改为引用官方安装说明。

声明解析继续识别标准的中文 `Issue 跟踪器` 标题，避免新版只接受高置信标题时，让既有中文工程失去已声明的后端。正文关键词仍只作为低置信证据，保留新版的谨慎判定。

## 派生版回归修正

链检查新增的 sandbox policy 查找保留 macOS 目录大小写和反斜杠字面量，避免选中另一个工作区的会话策略。

新版工具闸门将返回的卸载函数接入宿主 `effect`。宿主卸载时撤销全局设置订阅、事件监听、定时器和工具限制。动态加载晚于卸载时，立即清理已建立的订阅。

新增回归测试先复现以上两项问题，再定点验证修复。测试执行真实闸门，并从 Host 源码中取得真实策略回调，检查目录隔离行为。
