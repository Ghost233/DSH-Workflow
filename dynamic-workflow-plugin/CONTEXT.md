# Dynamic Workflow

本上下文描述计划中由脚本编排子代理任务的独立工作流。计划暂缓实施，使用 DSH 宿主及原生沙箱与审批边界。

## 语言

**Dynamic Workflow**：通过受限脚本定义子代理任务、依赖、阶段及交付结果的工作流。
_避免使用_：将脚本编排与原生代理任务混称。

**Workflow Run**：一份 Dynamic Workflow 脚本以一组输入启动的一次执行，具有独立身份和运行记录。
_避免使用_：把脚本定义或单个子代理任务称为 Run。

**Saved Workflow**：保存在所属项目中的、带名称、说明和参数声明的可复用 Dynamic Workflow 定义，独立于任何一次 Run。
_避免使用_：把一次运行记录或脚本草稿称为 Saved Workflow。

**Actor**：一个 Run 内拥有连续对话上下文的子代理身份；分配给同一 Actor 的任务按顺序执行。
_避免使用_：把 Actor 等同于一次任务或一个永久模块责任人。

**Ask**：分配给 Actor 的一次任务，完成时产生文本或符合声明类型的结果。
_避免使用_：把脚本中的每个表达式都称为 Ask。

**Resume**：延续同一 Run，并依据已记录结果重放已结算任务的恢复操作。
_避免使用_：把修改脚本后开始的新 Run 称为 Resume。

**Amend**：以修订后的脚本创建新 Run，并按资格复用前次 Run 结果的操作。
_避免使用_：把同一 Run 的故障恢复称为 Amend。
