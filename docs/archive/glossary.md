# 历史方案术语

## JEV 配置与代理监控

**JEV 引擎配置**：用户保存的一套 JEV 服务访问选择，确定请求的目标服务、访问身份和判断模型。多套配置可以同时启用，调用方通过 model 名字选择所需配置。
_避免使用_：主代理模型配置

**JEV 中心**：统一管理多套 JEV 引擎配置，并按调用方指定的 model 名字完成判断请求与结果返回的入口。
_避免使用_：全局当前引擎

**调用模型名**：消费插件向 JEV 中心指定的模型名字，在已启用的引擎配置之间唯一。默认沿用上游模型名，用户也可自定义为 quick、full、hard 等名称。
_避免使用_：推理强度档位

**上游模型名**：JEV 服务实际接收的判断模型标识。自定义调用模型名不改变请求中的上游模型名。

**监控告警**：对代理无输出、异常结束或疑似停滞的观察记录。测试阶段的告警不包含中止、重试或切换模型的授权。
_避免使用_：自动恢复指令

**连续无输出次数**：对同一被监控请求连续检查而没有发现输出的累计次数。恢复输出后清零，不由其他代理的活动替代。

**模型输出活动**：被监控模型产生新增正文、思考文字或工具调用参数。连接心跳和仅更新用量统计不属于模型输出活动。

**JEV 引擎不可用**：所选判断配置缺失、停用或无法完成请求的状态。它表示语义检测能力不足，不表示被监控代理卡死。

## 项目学习

**学习工作区**：以 DSH 工作区根目录确定的学习作用范围。同一学习工作区的会话共享已采用经验，不同工作区或 worktree 分别隔离。
_避免使用_：整个 Git 仓库、全局项目

**学习插件**：在 DSH 中提供原版 Harness² 学习过程、项目采用和经验使用管理的独立扩展。
_避免使用_：模型训练插件

**学习任务**：用于一次学习实验的任务与输入范围，由用户明确选择或标记任务完成、失败后确定。
_避免使用_：单轮回复

**实验选定结果**：Harness² 在一次学习实验中选定的配置和实验经验。它仍需获得项目采用，才能供日常任务使用。
_避免使用_：已验证提升、项目采用

**改进候选**：学习过程提出、尚未获得项目采用的经验或能力改动。
_避免使用_：已学会的能力、已生效经验

**项目采用**：用户明确决定把改进候选纳入项目后续任务的行为。
_避免使用_：实验选定、自动采纳

**人工判断采用**：候选通过配置可用性和相关确定性检查后，由用户根据执行对照与主观判断作出的项目采用。它不表示已经证明客观收益。
_避免使用_：客观验证通过

**已采用经验**：已获得项目采用的经验或能力改进，是否供后续任务使用由项目的经验使用开关决定。
_避免使用_：所有学习结果

**学习开关**：学习工作区是否允许收集新样本并安排新学习任务的选择。关闭后，已采用经验仍可继续使用。
_避免使用_：插件总开关

**经验使用开关**：学习工作区是否允许后续任务发现和加载已采用经验的选择。它与是否继续学习分别控制。
_避免使用_：自动采用开关

**项目经验库**：学习插件按学习工作区管理的学习结果与已采用经验集合。保存记录与供任务使用是分别控制的行为。
_避免使用_：全局经验库
