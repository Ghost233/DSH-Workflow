# 领域文档

本项目采用单上下文布局：根目录 GLOSSARY.md 保存术语，docs/adr/ 保存架构决策。

## 读取规则

- 探索代码库前读取 GLOSSARY.md；只加载与当前区域相关的 ADR。
- 若未来存在 GLOSSARY-MAP.md，则按它的指针读取相关上下文的术语表和 ADR。
- 文件不存在时继续工作，不以缺失为由自动创建领域文档。
- 规格、issue、设计和测试名称使用术语表的领域词汇；发现词汇缺口时记录给 domain-modeling。
- 输出与 ADR 冲突时明确指出冲突与理由，保留决定来源。
- ADR 记录设计与取舍；仓库代理约束以 AGENTS.md 为准，已取消的历史计划不构成实施要求。
