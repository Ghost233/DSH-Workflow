# 分类标签

| 规范角色 | 当前 GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 维护者需要评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给代理处理 |
| ready-for-human | ready-for-human | 需要人类实施 |
| wontfix | wontfix | 不会处理 |

工程类 skills 使用右列的实际标签。to-spec 发布规格时仅添加 ready-for-agent，不附加其他分类。
