# 以学习工作区隔离开关与经验

学习开关、经验使用开关和项目经验库，以 DSH 工作区根目录为作用范围。同一工作区中的多个会话共享已采用经验，不同工作区或 worktree 分别保存，首版不自动迁移或共享。

用户在 Q10 选择按工作区隔离。同一 Git 仓库的多个工作区可能使用不同分支、约束和实验环境，按整个仓库共享会扩大经验的适用范围，也会混合控制状态。这个决定固定了经验归属与采用记录的边界，避免后续把工作区隔离误作重复数据清理。

跨工作区复用通过用户明确的导出及项目管理处理。当前决策不新增自动经验同步。设计来源见[访谈记录](../analysis/2026-10-21-dsh-learning/discussion-record.md)。
