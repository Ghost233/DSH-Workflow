# 中枢 Bot 外置原则与注入第一机制

中枢 Bot（hub-bot-plugin）对 DSH 的唯一操作面是四个原生动作：注入提示词、新建会话、新建工作目录、fork 会话。它不改 DSH 的任何运行机制——用户日常直接使用的 DSH 与 bot 操作的是同一套会话体系，二者互不干扰。

选择注入（向既有会话的 inbox 投递 prompt）而非 fork 作为第一机制，因为注入不改变会话拓扑、保留全部上下文；fork 降级为路由选择项（独立开发场景），需显式或确认。

## Considered Options

- **fork-only**（每个远程任务 fork 新会话）：被拒绝——中断恢复和简单修改场景会在同一会话上累积大量无意义副本。
- **修改 DSH 增加远程控制接口**：被拒绝——用户需要持续升级维护 DSH 本体，任何侵入式修改都会成为升级负担。

## Consequences

- 插件的全部能力边界 = cordis 插件在进程内可调用的 DSH 原生 API。
- 用户手动开的会话与插件管理的会话是同种东西，用户可随时介入任何一层。
