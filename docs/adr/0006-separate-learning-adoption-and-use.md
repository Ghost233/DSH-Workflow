# 分开管理学习、项目采用和经验使用

学习过程自动生成改进候选，由用户查看证据和变更后明确采用。候选只有获得项目采用，才能供后续任务使用。学习过程内部选定的实验结果仍属于候选。

学习开关与经验使用开关按学习工作区分别保存，初始关闭。关闭学习后，项目可以继续使用已采用经验。DSH 的插件总开关负责停用整个插件。

用户在设计访谈第一轮确认这两个边界。单一开关会把继续学习与既有经验使用混在一起；将实验结果直接视为项目采用，则会绕过用户决定。分开管理也要求后续存储与状态变更保留这几种含义。

Q11 进一步确认采用门槛：候选先通过配置可用性和相关确定性检查。检查失败或配置无法映射时不可采用。主观收益缺少客观标准时，可以由用户明确人工判断采用，并保留相应标记。

Harness² 接入方式、经验归属和运行方式分别见 ADR0007 至 ADR0010。设计来源见[访谈记录](../analysis/2026-10-21-dsh-learning/discussion-record.md)。
