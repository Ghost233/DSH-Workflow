# 通过 DSH 插件接入原版 Harness² 核心

学习插件调用原版 Harness² 核心，保留提出候选、试跑、组合、结果选择、反思、实验经验库和预算记录。自研适配层连接 DSH 的任务、模型会话、执行证据和配置。DSH、Harness² 与其他第三方上游源码保持原样。

用户在澄清“独立插件”与“完整接入”后要求继续，采用完整核心接入作为首版目标。独立插件是 DSH 的交互入口，内部复用原版方法，替代最初自行实现简化学习流程的建议。

原版核心方法的复用与配置组件兼容分别验收。任务指导、经验、skills、辅助脚本，以及工具、子代理和自研插件配置，只有具备可靠 DSH 映射时才能执行。无法映射的项明确报告。现有代理约束、权限、凭据和第三方源码是固定边界。

原版实验选定结果继续留在实验范围内，再形成项目候选，由用户决定项目采用。运行位置、运行环境交付和具体配置映射尚待确定；本决策不代表已经证明 macOS 支持。设计来源见[访谈记录](../analysis/2026-10-21-dsh-learning/discussion-record.md)。
