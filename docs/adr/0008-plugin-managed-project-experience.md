# 由学习插件管理项目经验并显式导出

学习结果和已采用能力先保存在插件管理的项目经验库，通过插件按需提供。写入项目默认 skills 目录属于单独的显式导出行为。

用户在 Q6 确认此边界。采用后直接写入原生自动发现目录，会让经验继续由其他提供器加载，学习插件便无法完整控制后续使用。插件管理与显式导出分开，使经验使用开关的作用范围清楚，也保留项目写回的独立记录。

关闭经验使用后，停止后续加载。当前会话已经读入的内容继续保留，干净对照使用新会话。正式导出后的撤回规则仍需单独定义。设计来源见[访谈记录](../analysis/2026-10-21-dsh-learning/discussion-record.md)。
