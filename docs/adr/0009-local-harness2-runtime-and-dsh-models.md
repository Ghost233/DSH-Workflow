# 本机交付 Harness² 运行组件并复用 DSH 模型入口

学习插件优先在 Mac 本机运行原版 Harness²，独立运行组件随应用交付。应用启动时不下载环境，用户无需另装 Python 或启动 Linux 服务。运行前提缺失时明确报告，不自动改为其他优化流程。

任务试跑、候选生成、选择与反思均通过独立 DSH 会话执行。一次实验固定使用来源任务的模型配置，与主任务分别运行。JEV 只辅助局部语义判断。

用户在 Q7、Q8 确认此方案。独立 Linux 服务会增加部署、凭据与数据传输边界；复用 DSH 模型入口则保留既有模型选择和权限机制，也需要满足原版完整调用契约。

现成 Python 3.12.14 已在此 Mac 上跑通原版无模型 demo 的两种递归模式。该结果只证明最小核心流程可运行，DSH 适配、真实模型和应用交付继续独立验收。证据见[核心探针](../analysis/2026-10-21-dsh-learning/harness2-core-probe.md)。
