# L06：显式导出项目 skills

GitHub 工单：[H2-L06：显式导出项目 skills](https://github.com/Ghost233/DSH-Workflow/issues/54)。

本次仅发布。实施等待用户后续明确指令。

## 父项

https://github.com/Ghost233/DSH-Workflow/issues/48

## 要构建什么

用户把已采用 skill 及相关资源显式导出到项目，写入前查看范围和冲突。插件状态与正式项目文件分别管理，保留用户已有文件及人工修改。

## 验收标准

- [ ] 只有用户明确发起导出才写入项目默认 skills 范围，采用本身不自动写回。
- [ ] 导出前展示目标、资源和差异，并遵守 DSH 原生权限与审批。
- [ ] 校验路径、资源归属和版本，不允许越界写入代理约束、凭据或第三方源码。
- [ ] 同名已有文件或人工修改导致冲突时保留原内容，提供诊断和可审查差异。
- [ ] 导出记录来源、版本与内容证据，重复操作不会静默覆盖新的人工变更。
- [ ] 插件经验撤回和插件停用不自动覆盖或删除已导出项目文件。
- [ ] 完整流程通过公开操作测试，验证未提交和未跟踪文件得到保留。
