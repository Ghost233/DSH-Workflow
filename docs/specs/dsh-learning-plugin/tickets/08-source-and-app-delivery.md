## 验收标准

- [ ] 使用稳定插件身份与装配入口，源码和应用读取同一交付版本。
- [ ] 自研插件、原版核心、Python 运行组件和必要客户端产物纳入资源与内容摘要校验。
- [ ] 应用在没有系统 Python 的受控环境中可用，启动时不下载或调用包管理器。
- [ ] 组件缺失或内容校验失败明确报告，其他插件启动结果逐项真实呈现。
- [ ] 保留既有 JEV、原生监控、用户配置、凭据和主动停用选择。
- [ ] 新插件测试进入根完整测试发现，客户端及启动器相关检查覆盖最终内容。
- [ ] 完成固定的本地完整检查、应用构建与交付验证，分别记录真实结果。
- [ ] 核对上游干净、来源与许可证，不把真实模型效果或正式发布混入构建通过结论。
