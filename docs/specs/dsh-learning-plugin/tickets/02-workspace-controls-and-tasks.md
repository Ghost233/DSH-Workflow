## 要构建什么

用户在 DSH 中查看学习插件入口，按工作区保存“继续学习”和“使用已采用经验”，并把明确范围的当前或历史任务登记为学习任务。尚未具备实验环境时，也能看到具体准备缺口。

## 验收标准

- [ ] 两个开关初始关闭，保存后跨会话和重启保持，界面区分配置与实际状态。
- [ ] 同工作区多个会话共享状态，不同工作区及 worktree 分别隔离。
- [ ] 只在开启后收集当前工作区的新任务证据；关闭时停止新收集。
- [ ] 用户可标记任务完成或失败、点击“学习本次任务”，或明确选择历史任务。
- [ ] 学习任务记录输入范围、来源会话、来源模型配置和工程验证声明。
- [ ] 单次回复结束不直接启动整项学习，自身实验事件不循环产生新任务。
- [ ] 事件监听不阻塞主任务；插件停用释放所属监听与资源。
- [ ] 公开操作与界面行为由集成测试覆盖，现有 JEV 与监控入口继续可用。

## 被什么阻塞

无，可立即开始。
