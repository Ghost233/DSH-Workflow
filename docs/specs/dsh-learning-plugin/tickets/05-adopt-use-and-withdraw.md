本次仅发布。实施等待用户后续明确指令。

## 父项

## 要构建什么

用户查看证据后明确采用合法候选，后续任务通过插件按需加载已采用能力。用户可以撤回经验或关闭经验使用，停止后续加载并保留历史。

## 验收标准

- [ ] 原版实验选定结果、项目候选和已采用经验分别记录，未经采用不供日常任务使用。
- [ ] 采用检查版本与候选状态，配置或确定性检查失败的候选不可采用。
- [ ] 对缺少客观收益标准的合法候选，支持明确人工判断采用并保留标记。
- [ ] 已采用能力先保存在插件管理的项目经验库，通过独立提供入口按需发现和加载。
- [ ] 同工作区跨会话共享，不同工作区及 worktree 不互相提供经验。
- [ ] 关闭学习后可以继续使用已采用经验；关闭经验使用或撤回后停止后续加载。
- [ ] 当前会话已读内容不被伪装为已经清除，界面说明干净对照需要新会话。
- [ ] 采用、拒绝和撤回均保留版本与证据，后续读取不会把旧版本重新自动启用。
