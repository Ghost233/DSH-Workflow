## 要构建什么

维护者可以在 Mac 上通过独立运行组件启动固定版本的原版 Harness²，执行无模型任务并取得结构化结果。该组件可供学习插件调用，运行时不依赖用户另装 Python，也不下载环境。

## 验收标准

- [ ] 固定原版来源、完整提交、Python 运行时和许可证，构建与运行校验内容摘要。
- [ ] 上游源码保持原样，不注入补丁或重写核心学习流程。
- [ ] 在受控 PATH 中使用交付组件运行核心，不回退到系统 Python 或开发者绝对路径。
- [ ] 原版 parallel 与 sequential 无模型任务实际执行，结果与实验经验库可检查。
- [ ] 可检查真实退出码、错误和不完整结果，不把空入口或仅进程退出 0 视为完成。
- [ ] 组件缺失、版本不符或内容校验失败时明确拒绝运行，启动时不安装或下载。
- [ ] 新自研模块的归属、测试发现和固定验证入口接入仓库，验证记录绑定版本。
