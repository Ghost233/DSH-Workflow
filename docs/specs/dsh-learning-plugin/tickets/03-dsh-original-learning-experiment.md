## 要构建什么

用户发起一个具备实验环境的学习任务，独立 DSH 会话实际驱动原版 Harness² 的提出、试跑、组合、选择和反思。用户能查看执行阶段、实验结果和实际用量。

## 验收标准

- [ ] 原版核心通过真实任务适配器、改进器和选择器调用 DSH，不只生成摘要或模拟成功结果。
- [ ] 完整满足编辑文件、轨迹、交付物和调用结果契约，实验结果及经验由原版记录。
- [ ] 试跑、生成、选择与反思固定使用来源任务的模型配置；不可用时明确失败，不静默切换。
- [ ] 通过独立 DSH 会话执行，保持原生沙箱和审批，主任务继续。
- [ ] 默认 k=1，同一服务端实例全局一个活动实验，等待与运行状态分别可见。
- [ ] 仅消费工程已准备的可重复环境和固定命令；缺少环境时等待并说明原因。
- [ ] 输入基线与验证要求可核对，不覆盖用户未提交或未跟踪文件，不安装或复制工程依赖。
- [ ] 最少一类可映射配置贯穿任务入口、原版核心、DSH 执行与结果展示；两种模式使用可控模型响应验证。
- [ ] 实际执行次数、用量、成本可得性和错误有记录；未知项不记为零或成功。
