# L07：取消、中断恢复与资源收尾

本次仅发布。实施等待用户后续明确指令。

## 父项

https://github.com/Ghost233/DSH-Workflow/issues/48

## 要构建什么

用户关闭学习、停用插件或重新打开应用后，能查看真实的取消、中断和收尾状态。学习进程、DSH 会话与任务归属明确，主任务和其他工作区继续运行。

## 验收标准

- [ ] 关闭工作区学习立即停止新任务和调用，并取消或收尾所属活动实验。
- [ ] 无法立即取消时显示真实状态；迟到结果不能绕过状态检查进入采用或经验加载。
- [ ] 插件停用回收其全部监听、进程、会话和等待任务，释放全局实验名额。
- [ ] 清理异常单独记录，保留原始失败、取消或超时，不记为通过。
- [ ] 应用异常中断后保留实验与采用状态，不自动重放有副作用的实验或重复采用。
- [ ] 同时发生关闭、完成、采用和重启时，历史与当前版本保持一致。
- [ ] 主任务、其他插件、其他工作区状态及用户文件得到保留。
- [ ] 故障注入覆盖模型不可用、进程异常、状态保存失败与清理失败，保留真实退出证据。
