## 交付要求

- 同事务来源/身份/扣减到create、首append、prompt接纳、结果回执各边界SIGKILL重启，按同request/attempt/session/消息核对历史和执行次数。
- 跨进程不同请求争最后额度、同请求并发、损坏/失败保存、旧版本/旧lease及不确定会话均留原始证据；无确定授权不启动，已用额度不退。
- 受影响执行停止时，独立受控执行仍可启动；此处验证局部适配不全局封锁，完整Supervisor/Owner投影一致性留T-15。
- 如任何必要API仍不能证明幂等或安全停止，回填具体缺口并保持T-15阻塞，不把模拟层/少数正常序列或技术验证完成替代正向证据。
