# T-04 区分技术问题和真正需要用户的决定

规格：[R4](../../../superpowers/specs/2026-09-10-main-thread-spec-ticket-owner-dag-design.md)。合同：5.4、5.10 的分类合同、第8节AC-10/14及原业务授权边界。全局边界、状态定义及共同验收见[进度索引](../progress.md)。第 8–10 轮已实施并完成正式回归与只读审查；分类代理负责 model/convergence，主线程负责 Runtime/控制测试与文档。

## 交付行为与范围

“用户取消连接时如何释放资源”和固定命令缺失/exitCode 127按技术合同处理；真正改变业务承诺或缺少外部权限时才产生用户待决事项。环境失败保留精确错误和`runtime_environment`分类，不伪装成业务断言或用户授权问题。

范围之外：不取消旧 Workflow 原生审批，不自动授权 Registry、生产操作或发布。
