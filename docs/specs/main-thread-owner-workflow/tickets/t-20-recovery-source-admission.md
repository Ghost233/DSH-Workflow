## 交付要求

- Runtime仅从当前有效义务或其首次失败记录建立不可变来源；保留当前未关闭root映射和关闭历史。新模型ID、失败文案摘要、任务改名或换attempt不能自动获得新额度；无法核验来源/关联时返回技术拒绝并保留现场。
- 恢复意图与请求/attempt有持久映射，重放复用。只有新的、被Runtime接纳的恢复动作才能建立新请求；不能按入口或每次随机生成请求来规避幂等。
- 使用saveState的锁内current核验Workflow/执行版本/task/Owner，登记来源、调用T-13并保存；来源冲突、CAS/锁冲突、数据损坏、保存失败均不得产生可启动收据。有限重试必须重新读取，不重用旧余额计算。
- 在同事务预留执行身份并绑定request/attempt；其具体会话/prompt消费合同由T-21回填、T-22接纳。任何未验证的身份版本只可保存，不能被当作启动授权。
