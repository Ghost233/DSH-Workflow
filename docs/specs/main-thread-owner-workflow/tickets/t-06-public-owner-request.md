# T-06 校验公共 Owner 请求和决定引用

规格：[R4](../../../superpowers/specs/2026-09-10-main-thread-spec-ticket-owner-dag-design.md)。合同：5.2、5.8及[公共Owner变更协议V1](../contracts/public-owner-change-v1.md)；仅协议层。全局边界、状态定义及共同验收见[进度索引](../progress.md)。

## 交付行为与范围

缺版本、Owner 或证据的请求得到具体错误；同版本请求可去重，旧合同决定不能被当作当前解锁依据。

范围之外：不派会话、不自行登记 Owner、不实现消费者全量发现、不把只读建议当成修改批准。

## 模块与并行边界

当前实现/测试接缝：[runtime.mjs](../../../../owner-workflow-plugin/src/runtime.mjs)、[model.mjs](../../../../owner-workflow-plugin/src/model.mjs)、[control.test.mjs](../../../../owner-workflow-plugin/test/control.test.mjs)。这些是执行前需复核的证据位置，不是已经授予的写入清单。

统一请求/决定协议供 T-08 使用；若需提取 runtime 内的旧建议校验，先与其他 runtime 写入任务协调，禁止并行定义两套格式。

## 前置与解除条件

Blocked by：无。范围本身已明确；首批可开始资格不等于用户已授权实施。

已知阻塞：无本地任务前置。执行时若代码/合同已变化，记录漂移并由主线程处理，不猜测扩大范围。

## 交付要求

- 明确 request ID、来源 Ticket/AC、目标 Owner、代码/合同版本和证据引用；拒绝不完整记录。
- 按 R4 决定类别校验必要依据和影响信息；重复请求幂等，旧版本决定明确标为过期，消费者未知不能视为无影响。

## 验收映射与正式测试

关联：AC-06、AC-29。覆盖限于协议层，完整 AC 由进度索引的阻塞范围承接。

- 缺字段、不存在引用/Owner、同 ID 同版本重复、同 ID 不同内容冲突、过期决定、缺少消费者事实。
- 消费决定的协议门禁只能在版本有效且条件满足时给出就绪结果；没有调度副作用。

正式测试落点使用上述现有测试接缝；新增用例只归本行为一次。共享 S/A/B 场景、交付级测试只引用 CA-01，不在各工单复制。
