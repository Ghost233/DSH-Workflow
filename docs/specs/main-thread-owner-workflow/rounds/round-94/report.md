# R94 T08公共Owner判断会话验证报告

## 结论

T08技术验证完成。真实Harness能够以Registry中的公共S创建只读、永不审批的子会话，模型文本可回到主线程适配器并由T06协议登记；越界写入没有落盘，错误Owner和K1→K2期间迟到决定均被拒绝，超时与父取消都以无决定结束。

生产路线不能直接复用当前通用子会话。实际观察到：普通assistant文本没有专用结构化提交；该一次性通用会话结束后`readRaw(sessionId)`返回空，fresh Runtime没有可消费决定回执；两个并发只读会诊不会占用`activeOwners`或Runner reservation。可靠结论因此是“底层只读会话可复用，生产提交、持久化和容量生命周期必须新增”。

## 固定证据

正式候选串行运行T08、T06协议和既有结构化Owner advice三套，共22项通过，0失败、跳过或取消。T08六项覆盖：兼容K2回报、真实写入负例、身份不匹配、迟到决定、超时/父取消，以及两个并发会诊的容量负证据。
