- [orchestrator-documents.mjs](../../../../../owner-workflow-plugin/src/orchestrator-documents.mjs)：根身份核验与目标映射。
- [orchestrator-documents.test.mjs](../../../../../owner-workflow-plugin/test/orchestrator-documents.test.mjs)：根别名与内部链接等正反例。
- [orchestrator-documents-native.test.mjs](../../../../../owner-workflow-plugin/test/orchestrator-documents-native.test.mjs)：真实临时 Git 仓库预检后，经 Harness 原生工具验证根目录和子目录会话。
