# R100 CA01固定候选集中验收范围

本轮只执行唯一CA01：绑定当前Git基线、实际源码内容摘要、R4 Spec与全部31张Ticket，在同一候选上运行完整Owner插件回归。工作区已有未提交内容不被清理或提交，由`contentDigest`逐项前后复核；运行期间源码或Git HEAD变化即分类为`stale_candidate`。

验证图分为规划基础、规划激活、公共Owner协议、调度资源生命周期、S/A/B代表链、有界恢复、收敛与版本控制、历史/Git重放、平台安全/UI及集中验收分类十项。只有规划激活、公共Owner协议和调度资源生命周期都通过，S/A/B的K1→兼容K2联合项才运行；其他故障组保持独立，某项失败不会阻止无依赖证据采集。

正式结果须映射AC-01至AC-32，区分当前候选的集中执行证据与R79–R99已经固定的局部/故障注入证据。零用例、全部跳过、未运行、超时、取消、依赖阻塞、输出不完整或候选漂移均不能成为整体通过。
