## 本阶段验收

逐票使用既有启动器、正式 SDK 和实际服务/客户端的接缝进行红绿验证，合入候选后固定输入执行完整门禁和正式产物验证。首审、复盘、修复、复审通过后，阶段 PR 才进入集成分支。

用户已取消真实 macOS 登录启动验收，不重启或退出 macOS。S06 必须验证打开实际启动器后自动启动或复用服务；每次启动仅尝试一次，后续异常退出仍通知并保持停止，等待用户点击启动或重新打开启动器。关闭客户端不停止服务的边界保持。

任务准入和通知的预检笔记只提供源码事实，不是业务验收。当前发现、有效作业与负责人以交付入口和 `.build/independent-dsh-server/controller-state.json` 为准。

S02—S06 已合入阶段候选。S07 的 48 个自有文件与项目 CI、说明文档组成固定输入，在同一主工程环境通过 244 项 Node 测试、1 项真实上游桌面包适配测试和 60 项 Flutter 测试。新构建的 ARM64 Wrapper 通过迁移运行、嵌套严格签名和项目资源校验；14 个资源测试文件中的 18 项真实服务用例全部执行成功，无跳过。证据入口为 `controller-state.json` 中的 `s07Artifacts`。

这些结果不代替尚待完成的实机界面核对、阶段双轴审查、复盘和 CI，也不代表 S08 的跨客户端联合验收已经完成。生产测试包绑定固定源码摘要，最终已提交候选的干净构建由 S08 核对。
