## 本阶段验收

逐票使用既有启动器、正式 SDK 和实际服务/客户端的接缝进行红绿验证，合入候选后固定输入执行完整门禁和正式产物验证。首审、复盘、修复、复审通过后，阶段 PR 才进入集成分支。

用户已取消真实 macOS 登录启动验收，不重启或退出 macOS。S06 必须验证打开实际启动器后自动启动或复用服务；每次启动仅尝试一次，后续异常退出仍通知并保持停止，等待用户点击启动或重新打开启动器。关闭客户端不停止服务的边界保持。

任务准入和通知的预检笔记只提供源码事实，不是业务验收。当前发现、有效作业与负责人以交付入口和 `.build/independent-dsh-server/controller-state.json` 为准。
