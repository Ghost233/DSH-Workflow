## 必需证据

每项结果绑定具体候选提交、工具版本、真实命令、退出码和原始日志。系统通知须区分请求提交与实际交付，登录开关沿用既有隔离检查，启动器自动启动以真实应用和 Host 就绪为证据。用户明确取消真实 macOS 登录实测，不执行系统重启或退出登录，不把取消记为通过；其余环境拒绝、未知和缺失证据保留未完成。清理记录不能替代业务断言，SIGTERM 或 SIGKILL 回收不能替代正常退出证明。
