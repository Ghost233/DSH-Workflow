## 验收标准

- [x] SDK 状态与实际 Web 资源一致；监督进程仍活着但 Web 已断开时不将其误报为正在运行。
- [x] Web 运行身份来自真实业务连接，SDK 会话更换不伪造新业务实例，未知实例信息保持未知。
- [x] Desktop 状态使用可信后端运行记录和就绪观测；进程已确认存活但健康查询不可用时，保留运行事实并表达就绪信息不足。
- [x] SDK 日志与管理窗口呈现原始日志文本；未提供的写入时间、流类型保持未知，批次观测时间不冒充写入时间。
- [x] Web 重连或重启后日志按实际实例隔离，前一实例日志不被标成新实例内容。
- [x] 覆盖完整返回、限量读取和缓存确实丢弃内容的截断场景；恰好等于读取上限而未丢失内容时不误报截断。
- [x] 覆盖启动、运行、停止、后端健康不可用和日志换实例等应用边界场景，绑定候选、固定验证命令与原始证据；敏感访问凭据不出现在 SDK 状态、日志或声明中。
