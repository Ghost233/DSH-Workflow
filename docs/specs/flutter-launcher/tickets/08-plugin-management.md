## 验收标准

- [x] 插件页面展示真实来源、当前和最新版本、DSH 兼容信息及状态，未知信息如实表达，较窄窗口下仍可读取和操作。
- [x] 可更新项支持单项和全部可更新项操作，更新结果与实际受控插件版本一致。
- [x] 检查或更新失败时呈现原因与已完成部分，不把单项失败或第三方错误描述为全部成功。
- [x] 插件检查和更新期间不自动终止用户 Desktop 后端；需要重新加载时明确提示完全退出并重新打开 Desktop。
- [ ] 用户已恢复 Desktop 正常退出/重新打开、新 Host/租约和重开后实际加载版本验收；需取得当前候选原始正常成功证据，晚到或强制清理不代替通过，历史成功或失败保留。
- [x] 验收采用隔离资源和受控自研插件，遵守第三方源码保持上游原样的维护边界；记录候选、固定验证命令、原始退出证据、隔离安装版本与重开提示。原始重载成功仍作为历史证据保留。

## 固定验证入口与证据

- `engineering`：在 `macos-launcher/flutter` 执行 `bash check.sh`。锁定解析/格式/零诊断/Flutter适用完整测试；必须对应最终输入。
- `T08`：在 `macos-launcher/flutter` 执行 `dart run tool/application_probe.dart "$VALIDATION_APP_EXECUTABLE" --plugins-desktop-runtime "$VALIDATION_RUNTIME_RESOURCES"`。隔离受控自研包，真实安装/正常新Host加载。

占位变量必须在执行前冻结为实际ARM64应用/只读runtime/Release路径与完整SHA，连同命令、工具链、退出码及原始输出记录；占位草稿不是已执行证据。系统/默认SDK/外部焦点仅在已授权干净runner，禁止本地伪造CI环境绕过隔离守卫。健康来源迁移时沿用现成公开DSH观察，不新增服务架构。
