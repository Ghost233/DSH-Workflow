## 干净 CI 后续

主线程调度 disposable GitHub macOS runner，在 RUNNER_TEMP 创建阶段候选并写相对关联，运行：

```sh
dart run tool/application_probe.dart "$RUNNER_TEMP/t07-input.app/Contents/MacOS/DSH Workflow" --updates --system-ci
```

必须使用实际完整 Debug app，不设置假系统返回。系统模式初始实际状态要求 notRegistered，经真实 UI 注册后读取真实 native 状态 enabled 或 requiresApproval，再通过同一 UI 取消注册并核对 notRegistered，保存日志与截图。真实 NSWorkspace 接受的正确项目 URL 另记录为模式 NSWorkspace。若真实系统拒绝，保存错误与真实状态，不能把失败改成通过。

Apple将 requiresApproval 定义为已经注册、仍需用户批准；因此 pending状态要保持可取消注册。[Apple requiresApproval 文档](https://developer.apple.com/documentation/servicemanagement/smappservice/status-swift.enum/requiresapproval?language=objc)。注册受用户批准约束，[Apple register 文档](https://developer.apple.com/documentation/servicemanagement/smappservice/register%28%29)。CI 输出 `SYSTEM_APPROVAL_OBSERVED` 与实际状态；即使注册/注销通过，若没有真实观察到批准需求或系统拒绝，对应 criterion 仍未结算，不替用户批准，不凭源码映射补齐证据。CI尚未执行，本票仍未完成。
