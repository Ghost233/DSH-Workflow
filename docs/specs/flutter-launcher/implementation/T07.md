Apple将 requiresApproval 定义为已经注册、仍需用户批准；因此 pending状态要保持可取消注册。[Apple requiresApproval 文档](https://developer.apple.com/documentation/servicemanagement/smappservice/status-swift.enum/requiresapproval?language=objc)。注册受用户批准约束，[Apple register 文档](https://developer.apple.com/documentation/servicemanagement/smappservice/register%28%29)。CI 输出 `SYSTEM_APPROVAL_OBSERVED` 与实际状态；若实际返回 enabled，只记录 enabled；requiresApproval 未观察的事实保留，不凭源码映射声称已经覆盖。系统拒绝/不支持是条件行为，由主线程结合实际环境与执行路径审结，不要求受支持的 macOS 14+ 平台人为变成 unsupported，也不为未发生的拒绝制造无限阻塞。不替用户批准。首跑CI尚未执行注册/注销，本票仍未完成。
