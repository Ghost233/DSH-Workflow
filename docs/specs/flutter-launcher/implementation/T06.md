## 已编译的有界受控条件

gate 仅在 `#if DEBUG` 且 `testRoot=/private/tmp/dsh-t06-*/data`、固定 private owner 文件内容等于当前 Native PID 时启用。`entry-hold` 延迟真正 NSStatusItem hide；release 后才执行实际 hide、记录实际 `isVisible`/PID/uptime，再以真实可见性确认。归还 false 不受 gate 阻塞。取消或 timeout 是真实有界 native I/O 等待错误，经 FlutterError→正式 SDK `failed` 输出，不直接返回 fake success。timeout token 上限 3 秒，其余 12 秒以容纳正式 SDK 5 秒重连周期。

场景要求 late trace 出现真实 hide→restore 的单调顺序，最终 state entryVisible=true；旧 request 必须为真实 `StateError: connection lost`，不能把 TimeoutException 当断线。重连中先由新的 official session 完成 SDK openWindow，再 release 旧动作，之后再接管/归还；业务保持相同实际 Web UUID/Host lease/PIDs 与认证访问。每个 checkpoint 保存对真实资源的观测；断线时 `webStatus=null`，不伪造 SDK 状态，重连后重新核对 same instance。详见 [native-gate-plan.md](/private/tmp/dsh-flutter-implementation/T06/native-gate-plan.md)。这些仍是待执行条件，不能宣称已 green。
