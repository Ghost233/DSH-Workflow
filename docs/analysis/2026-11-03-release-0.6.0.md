# Ghost DSH Station 0.6.0 发布验证

## 变更

- 为日常 DSH 管理器增加版本识别。旧管理器仍在运行服务时保留现有服务；旧管理器处于停止状态时，提示退出并重新打开 Station，以免使用旧启动方式。
- 飞书授权入口加入 `im:chat.members:read` 和 `im:message.group_msg`；成员昵称读取使用可选的 `contact:user.base:readonly`。机器人列表显示 App ID，成员列表显示可用昵称及用户 ID。飞书敏感权限仍需按飞书要求审批和发布。
- 已运行的 Superagent 报告实际沙箱写入范围。新增独立项目时，只有能验证运行中项目的隔离状态且新项目目录不重叠，才允许继续。旧管理器没有隔离证明时需退出并重新打开 Station；修改现有项目仍需停止全部 Superagent。

## 本地验证

- 候选应用按 0.6.0 编译，完整项目测试通过 397 项（含真实打包 Host 就绪检查）。
- 启动两个真实、独立的候选 Superagent Host：同时运行、进程不同，目录写入范围相互隔离，原有测试文件保留。使用临时 profile 和模拟 GitHub CLI；执行保持暂停，没有接入飞书或真实仓库。
- Flutter 依赖锁、格式与静态检查通过，完整测试通过 98 项；发布流程本地回归通过 24 项。
- 隔离候选 Host 实际加载全部 9 个固定插件，版本与随包路径匹配；设置及侧栏入口均已逐项打开检查。
- 本地 0.6.0 ARM64 DMG 预检通过，镜像 CRC 和产物 SHA-256 校验通过。
- 飞书不 @ 机器人的真实群消息端到端链路本次未验证。

发布以仓库原有脚本构建、核对并由 GitHub Actions 创建正式资产；本地预检产物不是正式 Release。发布过程不安装或切换用户现有服务。
