# Matt 工程技能方法对照

本页保留 2026-09-10 分析中独立的技能方法对照，表内两个版本是当时读取的本地版本。已撤销运行机制的代码诊断、复现与整合计划已退出当前维护；原始报告仍可按 Git 历史和本轮原样证据快照核对。

| 项目 | Matt `implement-spec` | 当前 `ghost-matt-implement` |
| --- | --- | --- |
| 主要单元 | 规格和垂直切片工单 | 选定的一轮工单/AC |
| 并行方式 | 每个 implementer 单独分支/worktree，完成后 merger 合并 | 当前分支/工作区；同一文件一个写入者 |
