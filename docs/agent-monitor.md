# DSH 代理监控

自研插件只观察 DSH 原生主代理和子代理，产生告警、记录和状态信息，不中止、重试、换模型或发送干预消息。第三方 LLM 服务不改变原生代理身份。

当前实现包含无输出、异常结束和 JEV 语义停滞检测。分阶段验收与集成状态见[交付记录](./specs/jev-center-agent-monitor/delivery.md)，旧原型的固定配置与阈值不代表当前实现。

## 无输出检测

默认每分钟检查，连续五次没有模型输出活动时告警，之后每轮仍无输出就提醒。第五分钟有输出、第六分钟计一次时，第十分钟告警、第十一分钟再次告警，第十二分钟有输出则清零停止。

新增正文、思考文字和工具调用参数都算输出；心跳和仅更新用量统计不算。各代理、请求独立计数。模型完成后的长工具执行、审批、用户等待和空闲不误报，主动取消不当作失败。同轮重复事件去重；恢复只更新状态和记录时间，不弹窗。

## 配置与查看

从 DSH 原生“设置”或“插件”面板进入“JEV 中心”与“代理监控”。监控可以修改检查间隔、连续无输出次数、JEV 调用模型名、语义检测等待时间、连续语义异常次数及调试片段开关，写入标准 Settings。/agent-monitor/api/status 返回状态与配置描述，/agent-monitor/api/journal 提供持久记录。

记录位于 catalog 下 .dsh-workflow/agent-monitor/alerts.jsonl。默认记录元数据、判断概率、耗时和原因；调试片段默认关闭，密钥与认证请求头不入日志。告警提交 macOS 系统通知，实际显示验收由用户暂缓，提交接缝不等于实际送达。

JEV 中心通过标准 Settings 保存多套引擎字段，通过标准 credentials 保存密钥。不同调用模型名可以同时启用，默认沿用上游名，也可自定义；保存不调用模型，连接测试使用固定小题并返回实际模型版本与耗时。监控主、子代理共用所选名称，其他消费者可以同时调用另一个名称。

持续思考且没有正文或工具进展达到默认三分钟后，监控沿检查间隔调用中心；连续五次明确异常才告警，次数与等待时间独立可调。正常判断或实际进展记录恢复，未知与失败清零语义计数并显示具体不可用原因，不把引擎故障或重新可用当成代理恢复。缺失、停用、鉴权失败、服务错误与超时显示红色状态，确定性检测继续，系统不自动换引擎。

编辑、停用或删除配置只影响后续判断，在途请求按原配置完成或超时；删除配置保留 DSH 凭据。

源码 Web 入口将两个可配置插件登记到原生 profile，保证运行中可保存、同 profile 重启后保留；Desktop 由自研 bundle 装配。配置与凭据各自沿用标准保存来源。

## 验证边界

原验证覆盖标准接口、原生 spawn/fork 与 Agent Team；项目 profile 重启后保留设置与用户字段。通知模拟证明提交接缝，不等于实际送达。浏览器操作、完整门禁与双轴审查按交付记录推进。

没有付费模型调用，没有判断质量或零误报承诺。运行中的 DSH 服务未切换，旧启动器资源不会自动读取本分支源文件。
