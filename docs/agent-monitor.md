# DSH 代理监控

自研插件只观察 DSH 原生主代理和子代理，产生告警、记录和状态信息，不中止、重试、换模型或发送干预消息。第三方 LLM 服务不改变原生代理身份。

当前分阶段交付状态见[交付记录](./specs/jev-center-agent-monitor/delivery.md)。第一阶段完成无输出检测；异常结束和语义检测由 #16、#17 交付，旧原型的固定配置与阈值不再代表当前实现。

## 无输出检测

默认每分钟检查，连续五次没有模型输出活动时告警，之后每轮仍无输出就提醒。第五分钟有输出、第六分钟计一次时，第十分钟告警、第十一分钟再次告警，第十二分钟有输出则清零停止。

新增正文、思考文字和工具调用参数都算输出；心跳和仅更新用量统计不算。各代理、请求独立计数。模型完成后的长工具执行、审批、用户等待和空闲不误报，主动取消不当作失败。同轮重复事件去重；恢复只更新状态和记录时间，不弹窗。

## 配置与查看

从 Owner 仪表盘进入“JEV 中心”与“代理监控”。/agent-monitor 可修改检查间隔与连续次数，写入标准 Settings；/agent-monitor/api/status 返回状态与配置描述，/agent-monitor/api/journal 提供持久记录。

记录位于 catalog 下 .dsh-workflow/agent-monitor/alerts.jsonl。默认记录元数据和原因，不记录会话片段，密钥与认证请求头不入日志。告警提交 macOS 系统通知，实际送达需另行确认。

/jev-center 页面通过标准 Settings 保存引擎字段，通过标准 credentials 保存密钥。调用模型名默认沿用上游名，可自定义；保存不调用模型，连接测试使用固定小题并返回实际模型版本与耗时。第一阶段页面编辑一套配置，多配置管理和语义消费者在后续阶段。

源码 Web 入口将两个可配置插件登记到原生 profile，保证运行中可保存、同 profile 重启后保留；Desktop 由自研 bundle 装配。配置与凭据各自沿用标准保存来源。

## 验证边界

模拟覆盖真实 Host、标准接口、spawn/fork、Agent Team 和 Owner。Owner 模拟请求挂起后告警、恢复后正常完成；项目 profile 重启后保留设置与用户字段。通知模拟证明提交接缝，不等于实际送达。浏览器操作、完整门禁与双轴审查按交付记录推进。

没有付费模型调用，没有判断质量或零误报承诺。运行中的 DSH 服务未切换，旧启动器资源不会自动读取本分支源文件。
