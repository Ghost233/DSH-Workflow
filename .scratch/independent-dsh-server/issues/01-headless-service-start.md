# 01 — 从启动器和 SDK 启动并观察独立 DSH 服务

**要构建什么：** 用户不打开桌面客户端，即可从启动器或 MacLauncher SDK 明确启动 DSH 服务，看到真实实例状态和日志。退出并重新打开启动器后，仍能发现同一实例，既有配置和项目插件继续生效。对应规格用户故事 1、6、9、25、26。

**被什么阻塞：** 无，可立即开始。

**状态：** ready-for-agent

- [ ] 启动器和正式 SDK 均能明确启动真实 DSH 服务；未打开桌面客户端时，也能完成 profile、Office 组合和项目插件装配。
- [ ] 只有服务真实就绪后才显示 ready，状态包含真实实例标识；日志和失败原因可从管理入口观察。
- [ ] 重复或并发启动不会创建第二个业务实例，已有旧版实例时明确报告冲突，不终止或覆盖用户工作。
- [ ] 退出并重新打开启动器后，服务仍运行且实例标识保持，管理端重新连接同一服务。
- [ ] 沿用既有配置、凭据和持久化数据，保留 JEV、代理监控和已固定的项目插件，不创建另一套业务配置。
- [ ] 本机控制接口受到本机身份和文件权限保护，普通 Web 访问不能调用服务控制或读取凭据。
- [ ] 未完成的停止或重启能力不对外声明可用；通过真实启动器和 SDK 验证本票行为，测试清理仅处理自有隔离资源。
