# 05 — 服务异常退出后通知检查并保持停止

**要构建什么：** 服务意外退出后，用户收到 macOS 系统通知，得知需要检查日志并手动启动。即使启动器已退出，故障仍能被观察和通知；系统通知不可用时如实显示原因。对应规格用户故事 16、17、18、19。

**被什么阻塞：** 01 — 从启动器和 SDK 启动并观察独立 DSH 服务。

**状态：** ready-for-agent

- [ ] 故意使服务异常退出后，状态和日志明确记录故障，服务保持停止，不自动重启或额外重发任务。
- [ ] 独立管理逻辑发出提醒用户检查的 macOS 系统通知，启动器退出后重复该场景仍能通知。
- [ ] 主动停止服务不会发出异常退出通知，异常状态与用户操作能够区分。
- [ ] 通知权限拒绝、发送失败或通知能力不可用时记录真实原因，并可从管理入口读取。
- [ ] 手动启动后恢复正常服务观察，旧故障不会被当成新故障反复通知。
- [ ] 记录系统授权、通知请求提交和实际展示的证据；模拟发送成功不能代替系统展示，未知和缺失证据不记为通过。
