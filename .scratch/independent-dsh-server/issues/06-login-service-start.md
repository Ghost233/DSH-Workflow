# 06 — 登录后启动服务并保留后台运行

**要构建什么：** 用户在启动器开启登录启动后，下次登录自动启动 DSH 服务，不强制打开桌面窗口。关闭登录启动只影响后续登录行为，不中断当前业务。对应规格用户故事 6、20、21。

**被什么阻塞：** 01 — 从启动器和 SDK 启动并观察独立 DSH 服务。

**状态：** ready-for-agent

- [ ] 登录启动开关和系统实际注册状态一致，未知或系统拒绝状态如实展示。
- [ ] 启用后经过真实登录启动边界，能够启动独立服务并观察真实就绪状态，不强制打开 DSH 桌面窗口。
- [ ] 已有服务时登录启动复用同一实例，退出启动器后该服务继续运行。
- [ ] 停用后下次登录不自动启动服务，停用动作不停止当前运行服务。
- [ ] 测试遵守现有系统边界和隔离约定，不修改用户现有登录项来替代验收；真实系统结果与模拟结果分别记录。
