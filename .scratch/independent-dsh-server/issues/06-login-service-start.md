# 06 — 打开启动器后自动启动服务并保留后台运行

**要构建什么：** 用户打开启动器后自动启动或复用独立 DSH 服务，不强制打开桌面窗口；退出启动器后服务继续运行。保留现有登录启动开关，关闭它不影响当前业务。用户已取消真实 macOS 登录启动验收，不重启或退出 macOS。对应规格用户故事 6、20、21。

**被什么阻塞：** 01 — 从启动器和 SDK 启动并观察独立 DSH 服务。

**状态：** ready-for-agent

- [ ] 登录启动开关和系统实际注册状态一致，未知或系统拒绝状态如实展示。
- [ ] 启动真实启动器后自动启动独立服务并观察实际就绪，无需再点击服务启动，不强制打开 DSH 桌面窗口。
- [ ] 已有服务时重开启动器复用同一实例，退出启动器后该服务继续运行。
- [ ] 停用登录启动只影响后续是否自动打开启动器，不停止当前服务；以后手动打开启动器仍自动启动或复用服务。
- [ ] 每次启动器启动仅尝试启动一次；失败或后续服务异常退出不会触发循环重试，后续启动由用户点击启动或重新打开启动器触发。
- [ ] 沿用现有系统边界和隔离约定；真实 macOS 登录启动验收已按用户要求取消，不执行 macOS 重启、退出登录或新 GUI 登录，不以模拟结果宣称该系统路径通过。
