# 02 — 桌面端连接独立服务并保留原生能力

**要构建什么：** 用户从启动器打开桌面客户端，连接已运行的独立 DSH 服务。桌面端只持有连接，真正退出后服务与已接收任务继续运行，重开后能看到结果。保留既有账号、内嵌用量和充值页、目录选择、拖拽及 Office 能力。对应规格用户故事 2、3、4、5、7、8、23、24。

**被什么阻塞：** 01 — 从启动器和 SDK 启动并观察独立 DSH 服务。

**状态：** ready-for-agent

- [ ] 从启动器打开桌面端后，桌面端连接并报告独立服务的同一实例，能够读取既有工作区和会话。
- [ ] 服务不存在或接入版本不兼容时明确提示，不隐式启动服务、另起实例或替换运行服务。
- [ ] 关闭窗口和真正退出桌面端均不停止服务；服务已接收的任务继续执行，重开桌面端能看到结果。
- [ ] 账号登录、内嵌用量和充值页可用；专用凭据只传给受限的本机 Electron 主进程，不进入普通 Web 接口或日志。
- [ ] 同机目录选择、拖拽和 Office 能力通过真实回归，路径仍指向同一台 Mac。
- [ ] 必要桌面适配由主仓库保存并装配到固定上游基准，DSH 子模块保持干净，桌面端不再持有服务的启动和关闭权限。
