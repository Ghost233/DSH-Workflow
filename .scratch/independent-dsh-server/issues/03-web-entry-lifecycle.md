# 03 — 独立启停 Web 入口并连接同一服务

**要构建什么：** 用户从启动器或 MacLauncher SDK 单独启停 Web 访问服务，通过认证访问已有 DSH 服务。退出启动器或停止 Web 不停止业务服务；服务停止后，仍运行的 Web 入口明确显示服务不可用。对应规格用户故事 2、3、4、6、7、8、10、11、12、26。

**被什么阻塞：** 01 — 从启动器和 SDK 启动并观察独立 DSH 服务。

**状态：** ready-for-agent

- [ ] 启动器与 SDK 分别提供 Web 启动、回收、状态和日志操作，打开 Web 与启动服务是不同动作。
- [ ] 正确访问密码可连接已有服务，错误认证被拒绝；沿用局域网访问和设置写权限规则。
- [ ] Web 显示服务的真实实例和业务状态，重复启动及重连不新增业务实例或重复占用入口端口。
- [ ] 退出启动器或关闭浏览器后，已启动 Web 入口与同一服务继续运行，服务已接收的任务保持执行。
- [ ] 回收 Web 实际释放其访问资源，业务服务及已接收任务继续运行。
- [ ] 服务不可用时，已启动的 Web 入口仍保持自身状态并明确返回服务不可用，不打开桌面端或隐式启动服务。
- [ ] 重新连接新服务实例时，旧实例的认证状态和 WebSocket 不被误用；通过真实启动器、SDK 和浏览器验证。
