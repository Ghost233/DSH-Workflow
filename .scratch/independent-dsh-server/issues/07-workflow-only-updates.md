# 07 — 更新只检查本仓库 DMG 并统一组件交付

**要构建什么：** 用户从启动器和桌面端检查更新时，只看到本仓库发布的配套 DMG。DSH、桌面适配与插件通过仓库固定版本并统一交付，运行端不直接安装上游原版，也不因更新检查或客户端退出而停止共享服务。对应规格用户故事 27、28。

**被什么阻塞：** 02 — 桌面端连接独立服务并保留原生能力。

**状态：** ready-for-agent

- [ ] 启动器与桌面端更新检查只访问本仓库正式发布入口，并校验候选确实包含适用的正式 DMG。
- [ ] 上游原版桌面更新、强制更新策略和应用内直接换插件包的通道不能绕过仓库统一发布规则。
- [ ] 插件页面仍能展示实际固定版本和来源，并明确随本仓库 DMG 更新，不保留会直接安装上游包的操作。
- [ ] 检查更新、打开本仓库发布页和客户端退出不锁定或停止共享服务，不自动下载或安装发布资产。
- [ ] 实际服务替换遵守显式停机和任务确认规则，不静默替换正在运行的实例。
- [ ] 通过真实入口观察网络目标和服务状态，验证只检查本仓库 DMG，第三方源码保持原样。
